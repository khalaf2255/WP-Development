إنشاء خطاطيف مخصصة في إضافتك (Custom Hooks)

كيف تجعل إضافتك قابلة للتوسعة (Extensible) للمطورين الآخرين بـ do_action و apply_filters وشروط التسمية.

1. لماذا ننشئ خطاطيف مخصصة (Custom Hooks)؟

من أهم ممارسات المطورين المحترفين إتاحة **خطاطيف مخصصة (Custom Hooks)** داخل إضافتك. تتيح هذه الخطاطيف للمطورين الآخرين وتطبيقات Add-ons التعديل والتوسيع على إضافتك دون الحاجة لتعديل الكود المباشر لإضافتك!

  • إنشاء فعل مخصص: نستخدم الدالة do_action( 'myprefix_custom_action' ).
  • إنشاء فلتر مخصص: نستخدم الدالة apply_filters( 'myprefix_custom_filter', $data ).

2. تطبيق عملي 1: Action مخصص لإضافة حقول في صفحة الإعدادات

custom-action-provider.php
<?php
// 1. المطور الأصلي يُتيح Hook مخصص في نهاية صفحة الإعدادات
do_action( 'wporg_after_settings_page_html' );

// 2. مطور آخر يربط دالته ويحقن حقولاً جديدة في صفحتك!
function myprefix_add_settings() {
    echo '<p>حقل مخصص مُضاف من إضافة خارجية!</p>';
}
add_action( 'wporg_after_settings_page_html', 'myprefix_add_settings' );

3. تطبيق عملي 2: Filter مخصص لتغيير إعدادات CPT

custom-filter-provider.php
<?php
// 1. المطور الأصلي يمرر مصفوفة البرامترات عبر apply_filters
function wporg_create_post_type() {
    $post_type_params = array( 'public' => true );
    register_post_type(
        'my_cpt',
        apply_filters( 'wporg_post_type_params', $post_type_params )
    );
}

// 2. مطور آخر يُعدل برامترات CPT قبل تسجيله في ووردبريس
function myprefix_change_post_type_params( $params ) {
    $params['hierarchical'] = true;
    return $params;
}
add_filter( 'wporg_post_type_params', 'myprefix_change_post_type_params' );
