📘 التلخيص المترابط للموضوعات

١.١ القاعدة الذهبية في تطوير ووردبريس (The Cardinal Rule)

تعتبر القاعدة الذهبية الأساسية والمطلقة في بيئة تطوير ووردبريس هي: "عدم مساس أو تعديل ملفات النواة المباشرة (Don't Touch WordPress Core)". جميع الملفات البرمجية الموجودة في مجلدات النظام القياسية مثل wp-includes و wp-admin يُحظر تعديلها مباشرة تحت أي ظرف.

⚠️ الأسباب العلمية والتقنية للحظر (Why Core Edits Fail):
  • فقدان التعديلات مع التحديثات: تقوم شركة ووردبريس بتنفيذ تحديثات دورية تلقائية ويدوية للأنظمة (System Updates). عند كل تحديث، يتم مسح كافة ملفات المجلدات الأساسية واستبدالها بنسخة جديدة تماماً، مما يطمس أي تعديل مخصص جرى عليها.
  • الانهيار البرمجي والتعارض (Conflicts): التعديل المباشر يزيد من مخاطر التعارض الخطيرة مع الإضافات والقوالب الأخرى وتوقيف الموقع بشاشة الأخطاء القاتلة (Fatal Error).
  • صعوبة الصيانة: يصعب تتبع التغييرات وصيانتها عند خلط كود التطوير المخصص مع كود النظام الأصلي.

١.٢ الحل المعماري: الإضافات (Plugin Architecture)

لتجنب مساس النواة، يُعتمد على معمارية الإضافات (Plugins) كطبقة برمجية مستقلة تُحقن داخل النظام. الإضافة هي برنامج أو مجموعة من ملفات PHP المستقلة التي تتصل بـ ووردبريس لتوسيع ميزاته وإضافة وظائف جديدة دون كسر الكود الأصلي.

  • الإضافة البسيطة (Simple Plugin): قد تتكون الإضافة من ملف PHP واحد فقط يوضع داخل مجلد الإضافات wp-content/plugins/. تعتبر إضافة Hello Dolly النموذج المعياري الأكثر بساطة للتعلم.
  • المكونات الأساسية لإضافة ووردبريس:
    1. رأس الإضافة (Plugin Header): تعليق برمجي توثيقي في أوليّة الملف يتيح لووردبريس قراءته والتعرف على الإضافة وتفعيلها.
    2. الدوال البرمجية (PHP Functions): الكود والمنطق البرمجي المطلوب تنفيذه.
    3. الخطاطيف (Hooks): آليات اتصال لربط الدوال بأحداث ووردبريس الرسمية.

💻 كود الدرس البرمجي

أول كود إكاديمي معتمد لإضافة ووردبريس مخصصة تعمل كملف مستقل آمن:

📄 my-academic-plugin.php PHP
<?php /** * Plugin Name: My Custom Academic Plugin * Plugin URI: https://example.com/plugins/my-custom-plugin * Description: إضافة تعليمية لشرح مبادئ تطوير إضافات ووردبريس والقاعدة الذهبية. * Version: 1.0.0 * Author: Academic Developer * Author URI: https://example.com */ // منع الوصول المباشر للملف لأسباب أمنية if ( ! defined( 'ABSPATH' ) ) { exit; // Exit if accessed directly } // دالة مخصصة لعرض تنبيه تعليمي في لوحة التحكم function academic_custom_notice() { echo '<div class="notice notice-success is-dismissible">'; echo '<p>مرحباً بك! تم تحميل كود الإضافة بنجاح دون المساس بنواة ووردبريس!</p>'; echo '</div>'; } add_action( 'admin_notices', 'academic_custom_notice' );

📊 شبكة ربط المفاهيم والمقارنات

وجه المقارنة تعديل النواة (Modifying Core) استخدام الإضافات (Using Plugins)
تأثير التحديثات تُحذف كافة التعديلات فوراً وتُمحى بالكامل. تظل التعديلات محفوظة ومستقلة تماماً.
الأمان والصيانة منخفض جداً وعرضة للأخطاء القاتلة والتعارضات. عالٍ ويخضع لمعايير الأمان الرسمية والمستقلة.
التوافقية وإعادة الاستخدام محصورة في الموقع وتتسبب في تدمير الاستقرار. يمكن نقل الإضافة وتثبيتها على أي موقع ووردبريس آخر.

❓ أسئلة المراجعة واختبار الذات

📌 س1 (اختيار من متعدد): ما هي القاعدة الذهبية الأساسية في تطوير ووردبريس؟
✅ الإجابة النموذجية: عدم تعديل ملفات النواة (WordPress Core) إطلاقاً.
الشرح: لأن أي تحديث لنظام ووردبريس سيقوم باستبدال ملفات النواة ومسح التعديلات المباشرة.
📌 س2 (اختيار من متعدد): ماذا يحدث للتعديلات المباشرة التي تُجرى على ملفات wp-includes عند التحديث؟
✅ الإجابة النموذجية: تُمسح ويتم الكتابة فوقها وتُفقد بالكامل.
📌 س3 (اختيار من متعدد): ما هو الحد الأدنى المكون لإضافة ووردبريس بسيطة مثل Hello Dolly؟
✅ الإجابة النموذجية: ملف PHP واحد يحتوي على رأس الإضافة وبعض الدوال والخطاطيف.
📌 س4 (سؤال مقالي): لماذا يُحظر التعديل المباشر على ملفات WordPress Core؟
✅ الإجابة النموذجية: لأن ووردبريس يستبدل ملفات النواة عند كل تحديث جديد للنظام، مما يؤدي لمسح وفقدان أي تعديلات برمجية جرت عليها مباشرة، إلى جانب خطر التسبب في تعارضات برمجية وأخطاء قاتلة بالموقع.

⚡ قائمة الحفظ السريع ليلة الامتحان

  • القاعدة الذهبية: لا تقم أبداً بتعديل ملفات ووردبريس الأساسية (WordPress Core).
  • تُستخدم الإضافات (Plugins) كخيار حصري لتوسيع وظائف الموقع دون التأثر بالتحديثات.
  • أبسط إضافة تتكون من ملف PHP واحد فقط يوضع داخل مجلد wp-content/plugins/.
  • إضافة Hello Dolly هي النموذج المعياري للإضافة البسيطة المكونة من ملف واحد.
  • رأس الإضافة (Plugin Header) تعليق برمجي ضروري ليتعرف النظام على الإضافة وتفعيلها.
  • تحتوي الإضافة الأساسية على: Plugin Header، ودوال PHP، وخطاطيف (Hooks).
