أفضل الممارسات ومنع تضارب الأسماء (Best Practices & Naming Collisions)

تقنيات البادئات (Prefixing)، البرمجة الكائنية (OOP)، الهيكل المجلدي المنظم، والتحميل الشرطي is_admin.

1. منع تضارب الأسماء (Avoid Naming Collisions)

يحدث تضارب الأسماء (Naming Collision) عندما تستخدم إضافتك نفس اسم المتغير أو الدالة أو الكلاس الذي تستخدمه إضافة أخرى أو نواة ووردبريس في الـ Global Namespace. لحل هذه المشكلة، توجد طريقتان أساسيتان:

الطريقة الأولى: التسمية المسبوقة (Prefix Everything)

في البرمجة الإجرائية (Procedural PHP)، يجب إضافة **بادئة فريدة (Prefix)** لا تقل عن 4 إلى 5 أحرف لكل عنصر متاح في الـ Global Scope:

  • الدوال غير المعرفة داخل Classes أو Namespaces.
  • الكلاسات والـ Interfaces والـ Traits.
  • الـ Namespaces والـ Global Variables.
  • أسماء الـ Options والـ Transients في قاعدة البيانات.
🚨 بادئات يُحظر استخدامها تماماً: بما أنك تطور جزءاً من منظومة ووردبريس، يُحظر استخدام البادئات الخاصة بالنواة مثل: wp_ أو WordPress أو __ (الشرطتان السفليتان). كما يُحظر استخدام بادئات الإضافات الشهيرة (مثل woo_ لمواصفات WooCommerce).

2. أسلوب البرمجة الكائنية (Object Oriented Programming - OOP)

الأسلوب الأسهل والأحدث لمنع تضارب الأسماء هو كبسلة كود الإضافة بالكامل داخل **Class** أو **Namespace**:

includes/class-wporg-plugin.php
<?php
if ( ! class_exists( 'WPOrg_Plugin' ) ) {
    class WPOrg_Plugin {
        public static function init() {
            register_setting( 'wporg_settings', 'wporg_option_foo' );
        }

        public static function get_foo() {
            return get_option( 'wporg_option_foo' );
        }
    }

    WPOrg_Plugin::init();
}

3. الهيكل المجلدي المنظم والتحميل الشرطي (Folder Structure & Conditional Loading)

يُنصح بجمع الملفات ذات الوظائف المتشابهة في مجلدات فرعية واضحة داخل جذر الإضافة:

Recommended Directory Tree
/plugin-name
├── plugin-name.php    # الملف الرئيسي بالترويسة
├── uninstall.php      # ملف التنظيف عند الحذف
├── /languages/        # ملفات الترجمة (.mo / .po)
├── /includes/         # كود PHP والـ Core Classes
├── /admin/            # كود لوحة التحكم والـ Assets الخاصة بالإدارة
│   ├── /css/
│   ├── /js/
│   └── /images/
└── /public/           # كود الواجهة الأمامية للمستثمر الزائر
    ├── /css/
    ├── /js/
    └── /images/

التحميل الشرطي لكود لوحة التحكم (is_admin())

لفصل كود لوحة التحكم عن الواجهة العامة للموقع وتخفيف استهلاك الذاكرة، نستخدم الدالة الشرطية is_admin():

plugin-name.php
<?php
if ( ! defined( 'ABSPATH' ) ) {
    exit; // الحماية من الوصول المباشر
}

// تحميل كود لوحة التحكم فقط عند زيارة Admin Dashboard
if ( is_admin() ) {
    require_once __DIR__ . '/admin/plugin-name-admin.php';
}
