الحماية من ثغرات التزوير (Nonces & CSRF Protection)

ما هو الـ Nonce؟ حماية النماذج والـ AJAX والروابط، ودوال التوليد والتحقق القياسية.

1. ما هو الـ Nonce ولماذا نستخدمه؟ (Why use a Nonce?)

الـ **Nonce** هو رمز تفويض مؤقت (Hash) يساعد في حماية الروابط والنماذج من التزوير عبر المواقع (CSRF - Cross-Site Request Forgery). يمتد العمر الافتراضي للرمز بين **12 إلى 24 ساعة** لعملية ومستخدم معينين.

🚨 كيف تحدث ثغرة الـ CSRF بدون Nonce؟ افتراضياً، إذا قام المطور بإنشاء رابط حذف مقال مثل: post.php?post=123&action=trash، يمكن للمخترق وضع صورة خفية في موقع خارجي متضمنة هذا الرابط في الـ src! وعند زيارة المسؤول لذلك الموقع الخارجي، يرسل المتصفح الكوكيز تلقائياً ويتم حذف المقال دون علم المسؤول! أخذ رمز الـ Nonce بـ _wpnonce=b192fc4204 يمنع هذا الهجوم ويرد بـ 403 Forbidden.

2. دوال إنشاء الـ Nonce (Creating a Nonce)

  • في الروابط (URL): نستخدم الدالة wp_nonce_url( $url, 'trash-post_' . $post_id ).
  • في النماذج (HTML Forms): نستخدم الدالة wp_nonce_field( 'delete-comment_' . $comment_id ) وتطبع حقلين مخفيين تلقائياً.
  • في طلبات الـ AJAX أو الحالات المخصصة: نستخدم wp_create_nonce( 'my-action_' . $post_id ) لإنشاء الرمز مباشرة.
nonce-creation.php
<?php
// 1. إضافة Nonce إلى رابط
$secure_url = wp_nonce_url( $bare_url, 'trash-post_' . $post_id );

// 2. إضافة Nonce داخل نموذج Form
echo '<form method="post">';
wp_nonce_field( 'delete-comment_' . $comment_id );
echo '<input type="submit" value="Delete"></form>';

3. دوال التحقق من الـ Nonce (Verifying a Nonce)

nonce-verification.php
<?php
// 1. التحقق في صفحات لوحة التحكم (يقوم بإيقاف السكربت ورفع 403 تلقائياً)
check_admin_referer( 'delete-comment_' . $comment_id );

// 2. التحقق في طلبات الـ AJAX
check_ajax_referer( 'process-comment' );

// 3. التحقق اليدوي الخالص (يعيد true أو false)
if ( ! wp_verify_nonce( $_POST['my_nonce'], 'process-comment' . $comment_id ) ) {
    wp_die( 'Security check failed!' );
}
📌 تخصيص مدة حياة الـ Nonce: يمكنك تعديل المدة الإفتراضية لـ Nonce (24 ساعة) عبر الفلتر nonce_life. مثلاً لتقليلها إلى 4 ساعات:
add_filter( 'nonce_life', function() { return 4 * HOUR_IN_SECONDS; } );
