ترويسة الإضافة والحقول الـ 14 (Header Requirements)

شرح Plugin DocBlock، الحقول الـ 14 المتاحة، الحماية بـ Update URI، والحقول الحديثة مثل Requires Plugins.

1. الحد الأدنى الإجباري (Minimum Fields)

لكي يتعرف ووردبريس على ملف PHP كـ إضافة، يلزم وجود حقل إجباري واحد فقط في تعليق الترويسة وهو Plugin Name:

minimum-header.php
<?php
/*
 * Plugin Name: MY PLUGIN NAME
 */

2. تفكيك الحقول الـ 14 المتاحة (Available Header Fields)

اسم الحقل (Header Field) حالة الحقل الوصف والاستخدام التقني
Plugin Name إجباري (Required) اسم الإضافة الذي يظهر في قائمة الإضافات في لوحة التحكم.
Plugin URI اختياري صفحة الإضافة الرئيسية (يُمنع استخدام رابط wordpress.org هنا).
Description اختياري وصف كافٍ ومختصر للإضافة (يفضل أقل من 140 حرفاً).
Version اختياري رقم الإصدار الحالي (مثل 1.0 أو 1.0.3).
Requires at least موصى به أدنى إصدار لووردبريس تتوافق معه الإضافة (مثل 5.2).
Requires PHP موصى به أدنى إصدار لـ PHP مطلوب لتشغيل الإضافة (مثل 7.2).
Author اختياري اسم المطور أو المطورين (يفصل بينهم بفاصلة).
Author URI اختياري رابط موقع المطور أو صفحته الشخصية.
License موصى به الاسم المختصر لرخصة الإضافة (مثل GPLv2).
License URI اختياري رابط النص الكامل للرخصة.
Text Domain مهم للترجمة معرف الترجمة الخاص بالإضافة لاستخدامه مع gettext.
Domain Path اختياري مسار مجلد ملفات الترجمة (مثل /languages).
Network اختياري تحديد ما إذا كانت الإضافة تُفعل على مستوى الشبكة فقط (true).
Update URI حماية أمنية يمنع استبدال الإضافات الخاصة بتحديثات إضافة بنفس الاسم من دليلك الرسمي.
Requires Plugins حقل جديد (WP 6.5) قائمة التبعيات (Slugs) للإضافات الأخرى المطلوبة لتشغيل هذه الإضافة.

نموذج الترويسة الكامل الشامل (Full Header & DocBlock)

my-advanced-plugin.php
<?php
/**
 * File Level Description
 *
 * @package PluginPackage
 * @author Author Name
 * @copyright 2026 Author Name
 * @license GPL-2.0-or-later
 *
 * @wordpress-plugin
 * Plugin Name: My Advanced Plugin
 * Plugin URI: https://example.com/plugins/my-plugin/
 * Description: Handle the basics and advanced functionality neatly.
 * Version: 1.10.3
 * Requires at least: 5.2
 * Requires PHP: 7.4
 * Author: John Smith
 * Author URI: https://author.example.com/
 * License: GPL v2 or later
 * License URI: https://www.gnu.org/licenses/gpl-2.0.html
 * Update URI: https://example.com/my-plugin/
 * Text Domain: my-advanced-plugin
 * Domain Path: /languages
 * Requires Plugins: woocommerce, elementor
 */
⚠️ ملاحظة هامة حول مقارنة رقم الإصدار (Version Comparison Note): يستخدم ووردبريس الدالة القياسية في PHP المسماة version_compare() لمقارنة أرقام إصدار الإضافة مع التحديثات. تأكد دائماً أن رقم الإصدار الجديد يعتبر "أكبر" حسابياً في PHP. على سبيل المثال: الإصدار 1.02 يعتبر في PHP أكبر حسابياً من الإصدار 1.1!
