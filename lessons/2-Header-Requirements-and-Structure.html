📘 التلخيص المترابط للموضوعات

٢.١ ترويسة الإضافة (Plugin Header / DocBlock)

ترويسة الإضافة هي كتلة تعليق نصي مخصصة بلغة PHP يُطلق عليها Plugin Header أو DocBlock تضع في بداية الملف الرئيسي للإضافة. عندما يقرأ ووردبريس مجلد الإضافات wp-content/plugins/، يقوم بفحص الأسطر الأولى من الملفات بحثاً عن هذه الترويسة للتعرف على وجود الإضافة، اسمها، إصدارها، ومؤلفها، وعرضها في لوحة التحكم وتفعيلها.

💡 ملاحظة للمذاكرة:

رأس الإضافة (Plugin Header) هو المكون الإجباري الوحيد الذي يسمح لووردبريس بالتعرف على الملف كإضافة قابلة للتفعيل، وبدونه لن يتعرف النظام على الملف إطلاقاً وسيتعامل معه كملف PHP عادي.

٢.٢ حقول ترويسة الإضافة المعتمدة

تتضمن ترويسة الإضافة حقولاً إجبارية واختيارية توثق خصائص الإضافة:

حقل الترويسة (Header Field) الوصف والوظيفة الأكاديمية مستوى الإجبار
Plugin Name اسم الإضافة الساطع في قائمة الإضافات بـ Dashboard. إجباري (Mandatory)
Plugin URI رابط الصفحة الرسمية المخصصة للإضافة أو وثائقها. اختياري توثيقي
Description وصف مختصر يوضح وظيفة الإضافة للمستخدم. موصى به جداً
Version رقم الإصدار الحالي لمتابعة التحديثات (مثال: 1.0.0). موصى به جداً
Author اسم مطوّر الإضافة أو الشركة المبرمجة. موصى به جداً
Text Domain المعرف الفريد الخاص بالتدويل والترجمة اللغوية (i18n). موصى به للإضافات متعددة اللغات
Requires PHP الحد الأدنى المطلوب من إصدار PHP لعمل الإضافة بأمان. أمني موصى به

٢.٣ تشريح إضافة Hello Dolly المعيارية

تُعتبر إضافة Hello Dolly النموذج المعياري التاريخي الأول المرفق مع ووردبريس لتوضيح كيفية إنشاء إضافة بملف فريد:

  • حجم الملف: تتكون من قرابة 100 سطر برمجي فقط داخل ملف PHP واحد.
  • البنية البرمجية: تدمج بين ترويسة Plugin Header، مصفوفة نصوص مقتبسة من الأغنية، دالة استخراج عشوائي بلغة PHP، وتنسيق بصري CSS مصغر لعرض البيت النصي أعلى لوحة تحكم الأدمن.

💻 كود الدرس البرمجي (VS Code Dark Theme)

نموذج برمجي متكامل لترويسة الإضافة الرسمي المعتمد في وثائق مطوري ووردبريس:

📄 standard-plugin-header.php PHP
<?php /** * Plugin Name: Advanced Product Gallery * Plugin URI: https://example.com/plugins/advanced-product-gallery/ * Description: إضافة مخصصة لعرض معرض المنتجات بشكل تفاعلي وبطريقة احترافية. * Version: 1.2.0 * Requires at least: 5.8 * Requires PHP: 7.4 * Author: Ahmed Developer * Author URI: https://example.com/ * License: GPL-2.0 or later * License URI: https://www.gnu.org/licenses/gpl-2.0.html * Text Domain: advanced-product-gallery * Domain Path: /languages */ // منع الوصول المباشر للملف if ( ! defined( 'ABSPATH' ) ) { exit; // Exit if accessed directly } // بداية منطق الإضافة الرئيسي function apg_init_plugin() { // الكود البرمجي الخاص بالإضافة } add_action( 'plugins_loaded', 'apg_init_plugin' );

❓ أسئلة المراجعة واختبار الذات

📌 س1 (اختيار من متعدد): أي من الآتي يعتبر المكون الأهم ليتعرف ووردبريس على الملف كإضافة؟
✅ الإجابة النموذجية: رأس الإضافة (Plugin Header).
الشرح: يقرأ ووردبريس الترويسة في التعليق البرمجي الأول في أوليّة الملف للتعرف عليها وتفعيلها.
📌 س2 (اختيار من متعدد): كم عدد الأسطر التقريبي لكتلة الكود في إضافة Hello Dolly التاريخية؟
✅ الإجابة النموذجية: 100 سطر تقريباً.
📌 س3 (سؤال مقالي): اذكر المكونات الأساسية الموجودة في ملف إضافة ووردبريس البسيطة.
✅ الإجابة النموذجية: 1. رأس الإضافة (Plugin Header)، 2. الدوال البرمجية (PHP Functions)، 3. الخطاطيف (Hooks) لربط الدوال بالنظام.

⚡ قائمة الحفظ السريع ليلة الامتحان

  • رأس الإضافة (Plugin Header) ضروري في بداية الملف ليتعرف النظام على الإضافة.
  • اسم الإضافة Plugin Name هو الحقل الإجباري الوحيد داخل ترويسة التعليق البرمجي.
  • توضع ملفات الإضافات في المسار wp-content/plugins/ داخل مجلد الموقع.
  • إضافة Hello Dolly نموذج إرشادي لإضافة مكونة من ملف واحد وحوالي 100 سطر كود.
