التلخيص المترابط للموضوعات

تم دمج الأفكار المتشابهة والمكملة لبعضها من النصوص المدخلة تحت أقسام موضوعية واضحة للمذاكرة.

1. ## ١. المدخل والأساسيات وأفضل الممارسات الألمانية والأمنية (WordPress Plugin Basics & Security)

تعليم ووردبريس

١.١ مفاهيم تطوير الإضافات الهيكلية


تُعد إضافات ووردبريس (WordPress Plugins) المكون الأساسي لتوسيع وظائف المنصة دون التعديل على النواة البرمجية (Core).

* مفهوم الإضافة (Plugin Concept): هي مجموعة من الملفات البرمجية بلغة PHP تتكامل مع ووردبريس لإضافة وظائف جديدة أو تعديل سلوك قائم.
* البداية الصحيحة: يُنصح المطوّر ببدء رحلته من خلال استيعاب المفاهيم الأساسية وهيكلية الملفات قبل الانتقال إلى كتابة الشفرات المتقدمة.

١.٢ أفضل ممارسات الأمان (Security Best Practices)


تعتبر حماية البيانات وتأمين الشفرة البرمجية حجر الزاوية في تطوير الإضافات التنافسية.

* التحقق من صحة المدخلات (Input Sanitization): تصفية كافة البيانات القادمة من المستخدمين قبل معالجتها.
* الهروب من المخرجات (Output Escaping): تأمين البيانات قبل عرضها في المتصفح لمنع ثغرات XSS.
* التحقق من الصلاحيات (Nonce & Capability Checks): التأكد من أن المستخدم يملك الصلاحية المناسبة للقيام بالإجراء بطلب مشروع.

> 💡 ملاحظة للمذاكرة: لا تعتمد أبداً على بيانات المستخدم المدخلة دون فحص. استخدم دوال ووردبريس الآمنة مثل `sanitize_text_field()` و `esc_html()`.

```php
// مثال برمجي لتأمين المخرجات في ووردبريس
$user_input = sanitize_text_field( $_POST['user_data'] );
echo esc_html( $user_input );
```

2. ## ٢. آليات التفاعل والتكامل: الخطافات والخصوصية (Hooks & Privacy Management)

تعليم ووردبريس

٢.١ آليات الخطافات (WordPress Hooks System)


تُمثل الخطافات (Hooks) وسيلة التواصل المحورية بين الإضافة ونواة ووردبريس، وتُقسم إلى نوعين أساسيين:

| نوع الخطاف | الوظيفة الرئيسية | دوال الاستخدام التابعة | مثال عملي |
| :--- | :--- | :--- | :--- |
| الأفعال (Actions) | تنفيذ شفرات برمجية مخصصة عند نقطة محددة | `add_action()`, `do_action()` | إرسال بريد إلكتروني عند نشر مقال جديد |
| الفلاتر (Filters) | تعديل وتصفية البيانات قبل حفظها أو عرضها | `add_filter()`, `apply_filters()` | تعديل عنوان المقال أو محتواه قبل العرض |

```php
// مثال على الفلاتر (Filters)
function custom_title_prefix( $title ) {
return 'مهم: ' . $title;
}
add_filter( 'the_title', 'custom_title_prefix' );
```

٢.٢ إدارة الخصوصية والبيانات الحساسة (Privacy & Sensitive Data)


يتوجب على المطورين الالتزام بقوانين حماية البيانات العامة (GDPR):

* تصدير وحذف البيانات: استخدام أدوات ووردبريس المدمجة لتصدير أو مسح بيانات المستخدم بناءً على طلبه.
* سياسة الخصوصية: الإفصاح عن أي بيانات يتم جمعها عبر الإضافة وإضافتها لسياسة الخصوصية الخاصة بالموقع.

> ⚠️ تنبيه امتحاني هام: يختلف الفعل (Action) عن الفلتر (Filter) في أن الفلتر يستقبل قيمة ويقوم بإرجاعها معدلة، بينما الفعل ينفذ عملية دون الحاجة لإرجاع قيمة.

3. ## ٣. الوظائف والمكونات المدمجة في ووردبريس (Built-in WordPress Functionality)

تعليم ووردبريس

٣.١ قوائم الإدارة والإعدادات (Administration Menus & Settings API)


تسمح ووردبريس للمطورين بإنشاء لوحات تحكم مخصصة لإضافاتهم:

* قوائم لوحة التحكم (Administration Menus): إضافة صفحات جديدة في لوحة التحكم باستخدام `add_menu_page()`.
* واجهة برمجة الإعدادات (Settings API): حفظ وتحديث إعدادات الإضافة بأمان وسهولة.

٣.٢ أنواع المنشورات المخصصة والتصنيفات (Custom Post Types & Taxonomies)


توسيع ووردبريس من منصة تدوين إلى نظام إدارة محتوى شامل (CMS):

* أنواع المنشورات المخصصة (Custom Post Types - CPT): تعيين أنواع محتوى جديدة مثل (منتجات، دورات، عقارات).
* التصنيفات المخصصة (Custom Taxonomies): تنظيم المحتوى المخصص وتصنيفه (مثل: تصنيف حسب السعر أو القسم).

٣.٣ البيانات الوصفية والوسوم والرموز القصيرة والمستخدمين (Metadata, Shortcodes & Users)

* البيانات الوصفية (Metadata): تخزين معلومات إضافية مرتبطة بالمشاركات أو المستخدمين عبر Meta Fields.
* الرموز القصيرة (Shortcodes): تمكين المستخدمين من تضمين المحتوى الديناميكي داخل التدوينات باستخدام أقواس مربعة مثل `[my_shortcode]`.
* إدارة المستخدمين (Users & Roles): التعامل مع أدوار المستخدمين وزيادة صلاحياتهم بناءً على هيكل الإضافة.

4. ## ٤. التقنيات المتقدمة: واجهات البرمجة، الواجهات التفاعلية والمهام المجدولة (Advanced Technologies & Cron)

تعليم ووردبريس

٤.١ واجهة برمجة HTTP وتكامل الشبكات (HTTP API)


تمكن دوال HTTP API في ووردبريس الإضافة من إجراء طلبات خارجية بمرونة وإرسال واستقبال البيانات بصيغة JSON أو XML دون الحاجة لاستخدام `cURL` المباشر.

٤.٢ استخدام JavaScript و jQuery و Ajax (Client-side Integration)


لإضافة تفاعلية سلسة وتحديث البيانات دون إعادة تحميل الصفحة:

* إدراج السكريبتات (Enqueue Scripts): استخدام `wp_enqueue_script()` لإضافة ملفات JS وتجنب تكرار المكتبات.
* معالجة Ajax الآمنة: استخدام `wp_localize_script()` لتمرير متغيرات PHP والرموز الأمنية (Nonces) إلى ملفات JavaScript.

٤.٣ المهام المجدولة والترجمة الدولية (Cron Tasks & Internationalization - i18n)

* نظام كرون ووردبريس (WP-Cron): جدولة تنفيذ الشفرات في أوقات محددة (مثل إرسال تقارير يومية أو تنظيف قاعدة البيانات).
* الترجمة الدولية وتدويل الإضافات (Internationalization - i18n): تجهيز النص للترجمة باستخدام دوال مثل `__()` و `_e()` ليكون من السهل دعم لغات متعددة.

> 💡 ملاحظة للمذاكرة: يعمل نظام WP-Cron عند زيارة المستخدمين للموقع وليس كـ Daemon حقيقي على السيرفر، ما لم يتم إعداده ليعمل عبر سيرفر النظام.

5. ## ٥. نشر الإضافة وأدوات التطوير والمساهمة المجتمعية (Deployment, Developer Tools & Community)

تعليم ووردبريس

٥.١ التجهيز للنشر في دليل الإضافات الرسمي (Plugin Directory Preparation)


عند اكتمال الإضافة وتجربتها، يتم تحضيرها للنشر في دليل ووردبريس (WordPress.org Plugin Directory):

1. مراجعة الشفرة والتأكد من توافقها مع إرشادات المجتمع.
2. إنشاء ملف `readme.txt` يحتوي على وصف الإضافة، تعليمات التثبيت، والتغيرات (Changelog).
3. استخدام نظام التحكم بالنسخ SVN لرفع الإضافة للمستودع الرسمي.

٥.٢ أدوات المطور والمساهمة (Developer Tools & Community Involvement)

* أدوات التطوير (Developer Tools): استغلال إضافة Query Monitor أو بيئات التطوير المحلية للتأكد من عدم وجود أخطاء برمجية.
* المساهمة مجتمعياً (Community Contribution): الدليل البرمجي تم إنشاؤه بواسطة المجتمع ولأجل المجتمع، ويمكن للمطورين الانضمام لفريق التوثيق (Docs Team) لإثراء الدليل.

الربط بين الأمان والخطافات (Security & Hooks Integration)

تكامل وإضافة

يتم دمج أفضل ممارسات الأمان مثل فحص الصلاحيات ورموز Nonces داخل دالّة الخطاف (Hook Callback) لضمان عدم تنفيذ الإجراءات إلا من قِبل مستخدمين معتمدين وبطريقة آمنة.

💡 خلاصة الربط والامتحان:

تطور تخصيص البيانات: من المنشورات العادية إلى أنواع المنشورات المخصصة والتصنيفات

تطور أو تسلسل

تطورت ووردبريس من منصة مدونات تعتمد على التدوينات والصفحات فقط، إلى نظام CMS كامل يسمح بتعريف Custom Post Types و Custom Taxonomies وهياكل بيانات معقدة.

💡 خلاصة الربط والامتحان:

أنواع المنشورات المخصصة تمنح المطور المرونة لتحويل ووردبريس إلى أي تطبيق ويب متكامل.

المقارنة بين الأفعال (Actions) والفلاتر (Filters)

مقارنة واختلاف

الأفعال تتنفذ عند نقاط زمنية محددة لإضافة سلوك جديد، بينما الفلاتر تستقبل بيانات وتقوم بتعديلها وإرجاعها للنظام.

💡 خلاصة الربط والامتحان:

استخدم Actions لإضافة سلوك/إجراء، واستخدم Filters لتعديل البيانات قبل عرضها أو معالجتها.

التفاعل بين JavaScript و Ajax مع نظام ووردبريس

تكامل وإضافة

يربط المطور بين الواجهة الأمامية والواجهة الخلفية عبر إدراج JavaScript باستخدام `wp_enqueue_script` ومعالجة طلبات Ajax في الخلفية بواسطة Action Hooks مخصصة.

💡 خلاصة الربط والامتحان:

الجمع بين Ajax و Hooks يمنح المستخدم تجربة تفاعلية سريعة وديناميكية.

سؤال 9 (سؤال مقالي) متوسط

✅ الإجابة النموذجية: الأفعال (Actions) تُستخدم لتنفيذ وظائف وإجراءات معينة عند نقاط زمنيّة محددة أثناء تشغيل ووردبريس ولا تتطلب إرجاع قيمة، بينما الفلاتر (Filters) تستقبل بيانات ومحتوى، وتتيح تعديله ثم إرجاعه من جديد للنظام.

الشرح والمراجعة: Action ينفذ حدثاً، و Filter يعدل البيانات ويعيدها.

الشرح والمراجعة: معالجة البيانات الحساسة مطلوبة لضمان توافق الإضافة مع القوانين وحماية أمن المستخدمين.
