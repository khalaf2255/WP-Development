تعقيم وتنقية المدخلات (Sanitizing Data)

ماذا يحدث داخل sanitize_text_field، وكيف تُنقى البيانات قبل دخولها لقاعدة البيانات.

1. مفهوم تعقيم المدخلات (Sanitizing Data)

تعقيم المدخلات (Sanitizing Input) هو عملية تنظيف وتجرد وتصفية البيانات القادمة من مصدر غير موثوق قبل استخدامها أو حفظها في قاعدة البيانات عندما لا يكون التحقق المباشر من النمط (Validation) ممكناً.

sanitization-example.php
<?php
// تعقيم نص عنوان النموذج قبل تحديث Meta
$title = sanitize_text_field( $_POST['title'] );
update_post_meta( $post->ID, 'title', $title );

2. ماذا يحدث خلف الكواليس داخل sanitize_text_field()؟

عند تمرير النص إلى الدالة الشهيرة sanitize_text_field()، يُنفذ ووردبريس 5 خطوات متتالية تلقائياً لتصفية النص:

  1. فحص النص والتأكد من صحة ترميز UTF-8 وتجريد الترميزات المكسورة.
  2. تحويل أوسمة الأصغر من الأحادية (<) إلى كيانات HTML.
  3. تجريد وإزالة كافة وسوم HTML بالكامل (strip_tags).
  4. إزالة الفواصل السطرية (Line breaks)، التابات (Tabs)، والمسافات الزائدة (Extra White Spaces).
  5. تجريد الثمانيات والرموز الثنائية المعقدة (Octets).

3. حزمة دوال التعقيم بالنواة (Sanitization Functions)

دالة التعقيم (Sanitization Function) الاستخدام المخصص والتنقية
sanitize_email( $email ) تجريد كل الحروف والرموز غير المسموح بها في عناوين البريد الإلكتروني.
sanitize_file_name( $filename ) تطهير اسم الملف المرفوع وتجريد الرموز الخطيرة لمنع ثغرات السيرفر.
sanitize_hex_color( $color ) تأكيد وتنقية كود اللون Hex (مثل #ffffff).
sanitize_key( $key ) تحويل السلسلة إلى حروف صغيرة بدون مسافات لاستخدامها كمفاتيح إعدادات.
sanitize_title( $title ) تطهير النص المخصص ليكون Slug آمن في الروابط.
sanitize_url( $url ) تنقية وتعقيم السلسلة لتصبح رابط URL آمن وقابل للتخزين.
