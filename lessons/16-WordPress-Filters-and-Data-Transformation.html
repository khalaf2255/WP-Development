مرشحات ووردبريس وتعديل البيانات (Filters & Data Transformation)

تعديل البيانات بالمرشحات عبر add_filter، حظر الآثار الجانبية (Side Effects)، وإعادة البيانات المحولة دائماً.

1. مفهوم المرشح (Filters Concept)

المرشحات (Filters) هي النصف الثاني من نظام الخطاطيف في ووردبريس. تتيح للدوال استلام البيانات أثناء معالجتها في النواة، تعديلها، ثم إعادة إرسالها لاستكمال المسار.

🚨 القاعدة المعمارية لـ Filters: حظر الآثار الجانبية (No Side Effects)! على عكس الأفعال، يجب أن تعمل دالة الفلتر بشكل معزول تماماً (Isolated Manner). يُحظر طباعة أي شيء بـ echo أو التعديل على المتغيرات العامة (Global Variables). يجب أن تعيد الدالة البيانات بـ return دائماً وإلا سينكسر عرض البيانات في الموقع!

2. طريقة إضافة فلتر وتعديل عنوان المقال (the_title)

filter-title-example.php
<?php
// دالة الفلتر: تستلم العنوان، تعدله، وتعيده لـ WordPress
function wporg_filter_title( $title ) {
    return 'عنوان مميز: ' . $title;
}
add_filter( 'the_title', 'wporg_filter_title' );

3. تطبيق عملي: إضافة كلاس CSS لجسم الصفحة (body_class)

في هذا التطبيق، نستلم مصفوفة الكلاسات الخاصة بوسم <body>، نضيف إليها كلاس مخصص بشرط عدم التواجد في لوحة التحكم، ثم نعيد المصفوفة المعدلة:

filter-body-class.php
<?php
function wporg_css_body_class( $classes ) {
    if ( ! is_admin() ) {
        $classes[] = 'wporg-is-awesome';
    }
    return $classes; // إعادة المصفوفة المعدلة إجبارياً
}
add_filter( 'body_class', 'wporg_css_body_class' );
