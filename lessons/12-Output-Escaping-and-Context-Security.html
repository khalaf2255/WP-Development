تطهير المخرجات وقاعدة الهروب المتأخر (Output Escaping)

منع ثغرات XSS، القاعدة الذهبية (Always Escape Late)، وتطهير المخرجات حسب السياق البرمجي.

1. تطهير المخرجات (Escaping Output)

تطهير المخرجات (Escaping Output) هو عملية تأمين البيانات المطبوعة للمستخدم النهائي عن طريق تجريد الأكواد الضارة وسكربتات XSS المحقونة من السلسلة قبل العرض مباشرة.

🚨 القاعدة الذهبية: الهروب المتأخر دائماً (Always Escape Late)! يجب إجراء تطهير الهروب (Escaping) في أحدث لحظة ممكنة، وهي داخل أمر الطباعة echo نفسه، وليس أثناء تجهيز المتغيرات سلفاً. هذا يمنع أي كود في المنتصف من تعديل المتغير وتمرير ثغرة، كما يسهل مراجعة الكود برمجياً بلمحة سريعة!
escape-late-example.php
<?php
// ❌ طريقة مقبول ولكنها ليست الأفضل: التطهير المبكر في المتغير
$url  = esc_url( $url );
$text = esc_html( $text );
echo '<a href="' . $url . '">' . $text . '</a>';

// ✅ الطريقة الأفضل والموصى بها: الهروب المتأخر داخل الـ echo مباشرة
echo '<a href="' . esc_url( $url ) . '">' . esc_html( $text ) . '</a>';

2. دوال التطهير حسب السياق (Contextual Escaping Functions)

دالة التطهير (Escaping Function) السياق البرمجي المناسب (Context)
esc_html( $text ) للنصوص العادية المعروضة داخل وسم HTML (تزيل وتجرد وسم HTML).
esc_attr( $text ) للقيم المعروضة داخل خصائص الوسوم (HTML Attributes مثل class أو id).
esc_url( $url ) لعناوين الروابط المطلقة والمجهزة للطباعة في href أو src.
esc_js( $code ) للكود المكتوب داخل سكربتات جافاسكربت المباشرة Inline JS.
esc_textarea( $text ) للنصوص المعروضة داخل وسوم نموذج <textarea>.
wp_kses_post( $html ) عند الرغبة في عرض HTML آمن ومسموح به (مثل محتوى المقال والملاحظات).

3. دمج التطهير مع الترجمة (Escaping with Localization)

يوفر ووردبريس دوال مدمجة تجمع بين الترجمة والتطهير في دالة واحدة لتبسيط الكود:

escape-with-localization.php
<?php
// طباعة نص مترجم ومطهر كـ HTML
esc_html_e( 'Hello World', 'text_domain' );

// طباعة نص مترجم ومطهر داخل Attribute
esc_attr_e( 'Submit Order', 'text_domain' );
