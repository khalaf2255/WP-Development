مقدمة تطوير الإضافات ومفهوم الإضافة (What is a Plugin?)

لماذا نصنع الإضافات؟ وحماية النواة، والنطاق من إضافة Hello Dolly البسيطة إلى الأنظمة المتقدمة.

1. لماذا نصنع الإضافات؟ (Why We Make Plugins)

إذا كانت هناك قاعدة رئيسية أساسية واحدة في عالم تطوير ووردبريس (Cardinal Rule)، فهي:

🚨 القاعدة الأساسية: لا تلمس نواة ووردبريس (Don't Touch WordPress Core)!
هذا يعني أنه يُحظر عليك تماماً تعديل أي ملف من ملفات ووردبريس الأصلية في مجلدات wp-includes أو wp-admin لإضافة وظيفة جديدة. العلة التقنية المباشرة هي أن ووردبريس يقوم باستبدال وإعادة كتابة كل ملفات النواة بالكامل عند كل تحديث تلقائي، وبالتالي أي تعديل يضيع فوراً وتتوقف المنظومة.

حل هذه المشكلة هو الإضافات (Plugins): فالإضافات تمكنك من توسيع وتغيير وظائف ووردبريس بلا حدود دون مساس بالنواة إطلاقاً.

2. ما هي الإضافة؟ (What is a Plugin?)

الإضافات هي **حزم برمجية (Packages of Code)** تُعزز وتوسع الوظائف الأساسية لنظام ووردبريس. تتكون الإضافة بشكل رئيسي من كود PHP، ويمكن أن تشتمل أيضاً على ملاحق وملفات خارجية مثل:

🐘 PHP Logic
الكود الأساسي الذي يحتوي على الدوال والـ Hooks والمعالجات.
🎨 Front-end Assets (CSS & JS)
ملفات التنسيق والـ JavaScript للتفاعل في لوحة التحكم أو الموقع.
🖼️ Media & Static Assets
الصور والـ SVG والأيقونات والملفات المساعدة.

تدرج إمكانيات الإضافات (Scope Spectrum)

يمكن للإضافة أن تكون بسيطة للغاية أو على غاية من التعقيد بحسب المطلوب:

  • الإضافة الأبسط (Single-file plugin): ملف PHP واحد يتكون من ترويسة (Plugin Header) ودالة واحدة موصولة بـ Hook (مثال: إضافة Hello Dolly الشهيرة).
  • إضافة متوسطة: عرض روابط أحدث 10 مقالات على الموقع.
  • إضافة متقدمة (Full-featured System): نظام تذاكر دعم فني كامل (Support Ticketing System) يتضمن Custom Post Types، إشعارات بريدية، حالات تذاكر مخصصة، وبوابة تواصل مع العملاء!

3. دراسة حالة: إضافة Hello Dolly الكلاسيكية

إضافة Hello Dolly المرفقة افتراضياً مع ووردبريس هي نموذج عالي القيمة للمطورين الجدد. الإضافة تتكون من **ملف PHP واحد لا يتعدى 100 سطر**، وتوضح الهيكل الأدنى لأي إضافة سليمة:

hello-dolly-architecture.php
<?php
/**
 * @package Hello_Dolly
 * @version 1.7.2
 */
/*
Plugin Name: Hello Dolly
Plugin URI: http://wordpress.org/plugins/hello-dolly/
Description: This is not just a plugin, it symbolizes the hope and enthusiasm of an entire generation.
Author: Matt Mullenweg
Version: 1.7.2
*/

// 1. دالة تُمثل منطق البيانات (جلب أسطر الأغنية)
function hello_dolly_get_lyric() {
    $lyrics = "Hello, Dolly\nWell, hello, Dolly\nIt's so nice to have you back where you belong...";
    $lines  = explode( "\n", $lyrics );
    return wptexturize( $lines[ mt_rand( 0, count( $lines ) - 1 ) ] );
}

// 2. دالة الطباعة بالـ HTML وربطها بـ Action Hook في لوحة التحكم
function hello_dolly() {
    $chosen = hello_dolly_get_lyric();
    echo "<p id='dolly'>{$chosen}</p>";
}
add_action( 'admin_notices', 'hello_dolly' );

// 3. دالة تنسيق الـ CSS المباشرة
function dolly_css() {
    echo "<style>#dolly { float: right; padding: 5px; margin: 0; font-size: 11px; }</style>";
}
add_action( 'admin_head', 'dolly_css' );
✨ المزيّة الذهبية لمؤلفي الإضافات في WordPress.org: بصفتك مطور إضافات، لديك فرصة استثنائية لإنشاء أفكار برمجة يتم تثبيتها واستخدامها بواسطة الملايين من مستخدمي ووردبريس حول العالم. كل ما تحتاجه هو تحويل فكرتك إلى كود سليم عبر قواعد هذا الدليل.
