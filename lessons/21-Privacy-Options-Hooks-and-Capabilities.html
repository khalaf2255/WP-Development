الدرس 03 | قسم Privacy & Data Protection

خيارات وخطاطيف وصلاحيات الخصوصية (Options, Hooks & Capabilities)

المرجع الشامل لجميع الأفعال، الفلاتر، خيارات النظام، والصلاحيات الإدارية المتعلقة بالخصوصية.

1. مرجع خيارات وخطاطيف الخصوصية (Privacy API Reference)

توفر نواة ووردبريس مجموعة واسعة من الخيارات والخطاطيف (Actions & Filters) للتحكم الدقيق في طلبات الخصوصية، ورسائل البريد الإلكتروني، وتصدير ومسح الملفات:

النوع (Type) اسم الخطاف / الخيار / الصلاحية الوصف والاستخدام التقني
Option wp_page_for_privacy_policy يحتوي على ID صفحة سياسة الخصوصية المعينة للموقع.
Action user_request_action_confirmed يُطلق فور تأكيد المستخدم لطلب التصدير أو الحذف.
Action wp_privacy_delete_old_export_files حدث مجدول أوتوماتيكياً لتنظيف ومسح ملفات التصدير القديمة من السيرفر.
Action wp_privacy_personal_data_erased يُطلق بعد اكتمال الصفحة الأخيرة من آخر عملية مسح بيانات.
Filter privacy_policy_url لتعديل وفلترة رابط URL لصفحة سياسة الخصوصية برمجياً.
Filter the_privacy_policy_link لتعديل كود الـ HTML الخاص برابط صفحة الخصوصية المعروض في الفوتر.
Filter wp_privacy_personal_data_erasers لتسجيل دوال ممحاة البيانات الشخصية التابعة للإضافات.
Filter wp_privacy_personal_data_exporters لتسجيل دوال تصدير البيانات الشخصية التابعة للإضافات.
Filter wp_privacy_anonymize_data لتصفية وتجهيل البيانات المسجلة لتجريدها من الهوية.
Filter wp_privacy_export_expiration التحكم في الفترة الزمنية المسموحة للملفات قبل مسحها (الافتراضي 3 أيام).

2. الصلاحيات الإدارية الخاصة بالخصوصية (Privacy Capabilities)

يتم التحكم في أجهزة وأدوات الخصوصية داخل لوحة التحكم عبر 3 صلاحيات رئيسية قياسية (Capabilities). يمتلكها مدير الموقع (Administrator) افتراضياً:

الصلاحية (Capability Name) القائمة والواجهة المرتبطة في لوحة التحكم الهدف الأمني
erase_others_personal_data تتحكم في ظهور قائمة الفرعية مسح البيانات الشخصية (Erase Personal Data) تحت قسم أدوات (Tools). تمنح الإذن بحذف وتجهيل بيانات المستخدمين والزوار.
export_others_personal_data تتحكم في ظهور القائمة الفرعية تصدير البيانات الشخصية (Export Personal Data) تحت قسم أدوات (Tools). تمنح الإذن بتوليد وتصدير ملفات البيانات الشخصية.
manage_privacy_options تتحكم في ظهور القائمة الفرعية الخصوصية (Privacy) تحت قسم الإعدادات (Settings). تمنح الإذن بتعيين وإنشاء صفحة سياسة الخصوصية للموقع.
check-privacy-capability.php
<?php
// فحص صلاحية إدارة الخصوصية قبل إتاحة زر خاص في الإضافة
if ( current_user_can( 'manage_privacy_options' ) ) {
    // عرض خيارات إضافية خاصة بالامتثال لسياسة الخصوصية
}
