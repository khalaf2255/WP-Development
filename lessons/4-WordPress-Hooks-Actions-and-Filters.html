📘 التلخيص المترابط للموضوعات

٤.١ نظام الخطاطيف (WordPress Hooks Architecture)

الخطاطيف (Hooks) هي نقاط اتصال برمجية توفرها نواة ووردبريس لتسمح للإضافات بحقن أرقام ودوال مخصصة لتمكين التوسعة والتعديل دون مساس بالنواة (WordPress Core). تُعتبر الخطاطيف الحل التقني والتطبيقي المباشر لتنفيذ القاعدة الذهبية.

٤.٢ الفرق الجوهري بين الإجراءات (Actions) والمرشحات (Filters)

تنقسم الخطاطيف في ووردبريس إلى نوعين أساسيين محوريين:

  • الإجراءات (Actions - add_action): تُستخدم لتنفيذ أفعال أو أحداث برمجية إضافية عند وصول دورة حياة النظام لنقطة زمنية محددة (مثل إرسال بريد إلكتروني عند تسجيل مستخدم، أو طباعة كود في wp_footer). الإجراء لا يتطلب إرجاع قيمة عبر return.
  • المرشحات (Filters - add_filter): تُستخدم لاعتراض وتعديل البيانات قبل معالجتها أو عرضها على المتصفح (مثل تعديل عنوان المقال أو تصفية المحتوى). المرشح يستقبل متغيراً ويجب إرجاعه معدلاً بـ return إجبارياً.
⚠️ تنبيه امتحاني وبرمجي هام:

الفلاتر (Filters) تتطلب دائماً إرجاع القيمة المعدلة باستخدام كلمة return داخل الدالة، بينما الإجراءات (Actions) تقوم بتنفيذ مهمة ولا ترجع قيماً بالضرورة.

💻 كود الدرس البرمجي

مثال برمجي متكامل يوضح التطبيق العملي للـ Actions والـ Filters جنبًا إلى جنب:

📄 hooks-master-demo.php PHP
<?php /** * Plugin Name: Master Hooks Demonstration * Description: كود تطبيقي شامل لشرح الفرق بين Action Hooks و Filter Hooks. */ if ( ! defined( 'ABSPATH' ) ) { exit; } // 1. تطبيق Action Hook: تنفيذ حدث طباعة توقيع في نهاية الصفحة function academic_add_footer_notice() { echo '<div style="text-align:center; padding:10px; background:#e0f2fe;">'; echo 'تم تشغيل هذا الحدث عبر add_action في خطاف wp_footer'; echo '</div>'; } add_action( 'wp_footer', 'academic_add_footer_notice', 10 ); // 2. تطبيق Filter Hook: تعديل وعمل إرجاع لعنوان المقال function academic_modify_post_title( $title ) { // تعديل القيمة وإرجاعها بـ return return 'مهم: ' . $title; } add_filter( 'the_title', 'academic_modify_post_title' );

📊 شبكة ربط المفاهيم والمقارنات

وجه المقارنة الإجراءات (Actions) المرشحات (Filters)
الدالة المستدعاة للربط add_action( 'tag', 'callback' ) add_filter( 'tag', 'callback' )
القيمة المرجعة (Return) لا ترجع قيماً بل تنفذ أثراً جانبياً. إجبارية ويجب إرجاع القيمة بـ return.
الاستخدام الرئيسي إضافة سلوكيات أو طباعة أكواد عند حدث معين. تعديل وتصفية البيانات القائمة قبل العرض.

❓ أسئلة المراجعة واختبار الذات

📌 س1 (اختيار من متعدد): ما الفارق الرئيسي بين الإجراءات (Actions) والفلاتر (Filters)؟
✅ الإجابة النموذجية: الإجراء ينفذ حدثاً، بينما الفلتر يستقبل قيمة ويعيد تعديلها عبر return.
📌 س2 (سؤال مقالي): وضّح الفرق الجوهري بين الأفعال (Actions) والفلاتر (Filters) في نظام ووردبريس.
✅ الإجابة النموذجية: تُستخدم الأفعال لتنفيذ كود أو حدث برمجي عند نقطة زمنية معينة دون الحاجة لإرجاع قيمة، بينما تُستخدم الفلاتر لتعديل بيانات أو محتوى وإرجاعه بـ return لاستكمال معالجة الصفحة.

⚡ قائمة الحفظ السريع ليلة الامتحان

  • الخطاطيف (Hooks) هي نقاط اتصال برمجية تسمح بالتوسعة دون تعديل Core.
  • الإجراءات (Actions) تُستخدم لتنفيذ أحداث برمجية جديدة (add_action).
  • الفلاتر (Filters) تُستخدم لتعديل البيانات وتتطلب دائمًا استخدام return (add_filter).
  • الجمع بين Ajax و Hooks يمنح المستخدم تجربة تفاعلية سريعة وديناميكية.
