الدرس 02 | قسم Plugin Security

التحقق من البيانات والمقارنة الصارمة (Data Validation)

منظومات Safelist مقابل Blocklist، الفحص الصارم للأنواع (Strict Type Checking)، ودوال النواة المساندة.

1. مفهوم وتنسيق التحقق من البيانات (Data Validation)

التحقق من البيانات (Data Validation) هو عملية اختبار المدخلات مقابل نمط برلمجي محدد (Predefined Pattern) بهدف الخروج بنتيجة قطعية محددة: **إما صالح (Valid) أو غير صالح (Invalid)**.

📌 الفرق الجوهري بين Validation و Sanitization: الـ Validation يقوم بفحص المدخل ورفضه بالكامل إذا لم يطابق الشروط فوراً، أما الـ Sanitization فيقبل المدخل ولكن يقص منه الأحرف غير المرغوبة. لذلك، يُفضل التحقق والرفض المبكر دائماً!

2. فلسفة القائمة المسموحة (Safelist & Strict Type Checking)

أقوى فلسفة في التحقق هي **الصف المسموح (Safelist)**: قبول المدخلات فقط إذا كانت مطابقة لقائمة مسبقة ومحددة من القيم الموثوقة. وعند مقارنة القيمة القادمة مع القائمة، **يجب استخدام المقارنة الصارمة (Strict Comparison ===)** وتمرير true في دالة in_array لمنع التجاوز الهش بـ Type Coercion في PHP:

strict-validation.php
<?php
$untrusted_input = '1 malicious string';
$safe_values     = array( 1, 5, 7 );

// ❌ مقارنة مرنة خطيرة (Loose Comparison): '1 malicious string' == 1 ستكون true!
// ✅ مقارنة صارمة آمنة (Strict Comparison): تمرير true للبرامتر الثالث
if ( in_array( $untrusted_input, $safe_values, true ) ) {
    // البيانات صالحة تماماً
} else {
    wp_die( 'Invalid data' );
}

3. تطبيق عملي: التحقق من مفاتيح الترتيب (OrderBy Safeguard)

لحماية الاستعلامات القادمة من النموذج عند اختيار ترتيب المقالات وتجنب ثغرات SQL Injection عبر `ORDER BY`:

validate-orderby.php
<?php
$allowed_keys = array( 'author', 'post_author', 'date', 'post_date' );

// 1. تعقيم المفتاح إلى حروف صغيرة أحادية
$orderby = sanitize_key( $_POST['orderby'] );

// 2. التحقق من القائمة المسموحة بمقارنة صارمة Type Safe
if ( in_array( $orderby, $allowed_keys, true ) ) {
    // تنفيذ الاستعلام بأمان كامل
}

4. أهم دوال التحقق المتاحة بالنواة (Core Validation Functions)

اسم الدالة (Function) الوصف والاستخدام البرمجي
is_email( $email ) يفحص ما إذا كانت السلسلة صيغة بريد إلكتروني صالحة ومطابقة للمعايير.
username_exists( $username ) يفحص ما إذا كان اسم المستخدم موجوداً بالفعل في قاعدة البيانات.
term_exists( $term, $taxonomy ) يفحص ما إذا كان التصنيف أو الوسم موجوداً في التاكسونومي المعطى.
validate_file( $file_path ) يتأكد أن مسار الملف المدخل هو مسار حقيقي سليم لا يحتوي على Directory Traversal (`../`).
