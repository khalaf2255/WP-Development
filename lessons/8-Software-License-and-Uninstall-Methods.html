الترخيص البرمجي وطرق الحذف والتنظيف (License & Uninstall Methods)

التثبيت القانوني GPLv2+، التمييز بين Deactivation و Uninstall، والبناء الآمن لملف uninstall.php.

1. تضمين ترخيص البرمجيات (Including a Software License)

تتم إتاحة معظم إضافات ووردبريس تحت رخصة **GPLv2 أو أحدث** المتوافقة مع ووردبريس ذاته. يُفضل دائماً توضيح الترخيص في تعليق الترويسة ووضع كتلة تعليق الترخيص (License Block) في بداية الملف الرئيسي للإضافة لحماية الحقوق وتحديد المسؤولية.

license-block-header.php
<?php
/*
 * {Plugin Name} is free software: you can redistribute it and/or modify
 * it under the terms of the GNU General Public License as published by
 * the Free Software Foundation, either version 2 of the License, or
 * any later version.
 *

 * but WITHOUT ANY WARRANTY; without even the implied warranty of
 * MERCHANTABILITY or FITNESS FOR A PARTICULAR PURPOSE. See the
 * GNU General Public License for more details.
 */

2. التمييز المعماري: التعطيل (Deactivation) مقابل الحذف (Uninstall)

يقع بعض المطورين غير المبتدئين في خطأ استخدام Deactivation Hook لحذف بيانات قاعدة البيانات. الجدول التالي يوضح الفرق المعماري الواجب اتّباعه:

السيناريو والاختبار عند التعطيل (Deactivation Hook) عند الحذف النهائي (Uninstall Hook)
تفريغ الكاش والملفات المؤقتة (Flush Cache / Temp) ✅ نعم ❌ غير مطلوب
تفريغ وتحديث الروابط (Flush Permalinks) ✅ نعم ❌ غير مطلوب
حذف الإعدادات والخيارات من {$wpdb->prefix}_options ❌ ممنوع قطعياً ✅ واجب لتنظيف قاعدة البيانات
إسقاط الجداول المخصصة من $wpdb ❌ ممنوع قطعياً ✅ واجب لتنظيف قاعدة البيانات

3. الطريقة القياسية للحذف: ملف uninstall.php

عند حذف الإضافة من لوحة التحكم، يبحث ووردبريس تلقائياً عن ملف uninstall.php في جذر الإضافة وينفذه. يجب حماية هذا الملف بالثابت WP_UNINSTALL_PLUGIN لمنع تشغيله المباشر عبر المتصفح:

uninstall.php
<?php
// 1. فحص الحماية الأمني الحاسم: التأكد أن ووردبريس هو من استدعى الملف
if ( ! defined( 'WP_UNINSTALL_PLUGIN' ) ) {
    die;
}

// 2. حذف خيارات الإضافة مخزنة في wp_options
$option_name = 'wporg_option';
delete_option( $option_name );

// لدعم الشبكات المتعددة Multisite
delete_site_option( $option_name );

// 3. إسقاط الجداول المخصصة عبر $wpdb
global $wpdb;
$wpdb->query( "DROP TABLE IF EXISTS {$wpdb->prefix}mytable" );
