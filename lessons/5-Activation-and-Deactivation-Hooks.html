خطاطيف التفعيل والتعطيل (Activation & Deactivation Hooks)

كيف تشغل الإجراءات عند تفعيل أو تعطيل الإضافة، وحل مشكلة أخطاء 404 الشهيرة مع Permalinks.

1. خطاطيف التفعيل والتعطيل (Activation & Deactivation Hooks)

توفر خطاطيف التفعيل والتعطيل طرقاً لتنفيذ روتينات برمجية فور ضغط المستخدم على زري **تفعيل (Activate)** أو **تعطيل (Deactivate)** في لوحة التحكم.

  • عند التفعيل (Activation): يمكنك إنشاء جداول مخصصة في DB، وضع قيم إعدادات افتراضية، أو تحديث قواعد الروابط (Rewrite Rules).
  • عند التعطيل (Deactivation): يمكنك تنظيف الملفات المؤقتة، إزالة الـ Transients والـ Cache، وتفريغ قواعد الروابط.

2. طريقة التسجيل والكود القياسي (Registration Method)

includes/activation-deactivation.php
<?php
// 1. تسجيل دالة التفعيل
register_activation_hook( __FILE__, 'pluginprefix_activate' );

// 2. تسجيل دالة التعطيل
register_deactivation_hook( __FILE__, 'pluginprefix_deactivate' );
📌 المراجعة المعمارية للمسار المعطى: البرامتر الأول في كلتا الدالتين يشير إلى **المسار المطلق للملف الرئيسي للإضافة** (والذي يتضمن ترويسة Plugin Header). إذا قمت بكتابة هذه الدوال داخل ملف فرعي مستقلاً، يجب تمرير مسار الملف الرئيسي بدلاً من __FILE__.

3. تطبيق عملي حقيقي: حل مشكلة 404 مع Custom Post Type

أشهر تطبيق عملي لـ Activation Hook هو تحديث قواعد الروابط الدائمة (Permalinks) لتجنب أخطاء الصفحة غير موجودة 404 بعد تسجيل CPT جديد:

cpt-activation-example.php
<?php
/**
 * 1. تسجيل Custom Post Type عند الـ init
 */
function pluginprefix_setup_post_type() {
    register_post_type( 'book', array( 'public' => true ) );
}
add_action( 'init', 'pluginprefix_setup_post_type' );

/**
 * 2. دالة التفعيل: تسجيل الـ CPT وتحديث الـ Permalinks
 */
function pluginprefix_activate() {
    // تشغيل تسجيل الـ CPT حتى يتعرف عليه النظام في الذاكرة
    pluginprefix_setup_post_type();
    // تفريغ وتحديث قواعد الروابط فوراً لمنع 404
    flush_rewrite_rules();
}
register_activation_hook( __FILE__, 'pluginprefix_activate' );

/**
 * 3. دالة التعطيل: إزالة الـ CPT وتطهير الـ Permalinks
 */
function pluginprefix_deactivate() {
    unregister_post_type( 'book' );
    flush_rewrite_rules();
}
register_deactivation_hook( __FILE__, 'pluginprefix_deactivate' );
🚨 تحذير: التجميد ليس حذفا! لا تقم أبداً بمسح الخيارات المخزنة في wp_options أو إسقاط الجداول في دالة التعطيل register_deactivation_hook. التعطيل مجرد إيقاف مؤقت، أما مسح البيانات فيتم فقط في ملف uninstall.php.
