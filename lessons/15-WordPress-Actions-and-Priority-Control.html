أفعال ووردبريس والتحكم بالأولويات (Actions & Priority)

كيفية إضافة الأفعال بـ add_action، إحكام ترتيب التنفيذ عبر الأولوية (Priority)، وتمرير المعاملات المتقدمة.

1. طريقة إضافة فعل (Adding an Action)

تتضمن عملية إضافة فعل خطوتين أساسيتين:

  1. إنشاء دالة Callback: دالة PHP عادية مسبوقة ببادئة تنفذ الإجراء المطلوب عند استدعائها.
  2. ربط الدالة بالفعل (Hooking): استخدام الدالة القياسية add_action() لربط الدالة باسم الفعل بالنظام.
basic-action.php
<?php
function wporg_callback() {
    // تنفيذ إجراء معين (مثل كتابة سجل أو إضافة خيار)
}
add_action( 'init', 'wporg_callback' );

2. نظام الأولويات (Priority Control)

يمكن ربط العديد من الدوال بنفس الفعل (مثل الـ init الذي يتم استخدامه بكثرة). يحدد ووردبريس ترتيب تنفيذ الدوال المرتبطة بناءً على **الأولوية (Priority)** المعطاة كالبرامتر الثالث في add_action():

  • الأولوية الافتراضية هي 10 عند عدم تحديد قيمة.
  • القيم الأصغر (مثل 9) تنفذ أولاً قبل القيمة الافتراضية.
  • القيم الأكبر (مثل 11) تنفذ لاحقاً بعد القيمة الافتراضية.
  • إذا تساوت الأولوية لعدة دوال، يتم تنفيذها بحسب ترتيب تسجيلها الكودي.
priority-example.php
<?php
add_action( 'init', 'wporg_callback_run_me_late', 11 );
add_action( 'init', 'wporg_callback_run_me_normal' );     // افتراضي 10
add_action( 'init', 'wporg_callback_run_me_early', 9 );
add_action( 'init', 'wporg_callback_run_me_later', 11 );

// ترتيب التنفيذ الفعلي في ووردبريس سيكون:
// 1. wporg_callback_run_me_early (أولوية 9)
// 2. wporg_callback_run_me_normal (أولوية 10)
// 3. wporg_callback_run_me_late (أولوية 11 - سجلت أولاً)
// 4. wporg_callback_run_me_later (أولوية 11 - سجلت ثانياً)

3. عدد المعاملات المستقبلة (Accepted Arguments)

في بعض الأحيان يرسل الفعل بيانات إضافية للدالة. على سبيل المثال، عند حفظ المقال، يُطلق ووردبريس الفعل save_post ممرراً برامترين: ID المقال وكائن المقال نفسه ($post). لاستقبال كلا البرامترين، يجب تحديد العدد **2** كبرامتر رابع في add_action():

accepted-args.php
<?php
// تحدد القيمة 2 كـ accepted_args لاستقبال $post_id و $post
add_action( 'save_post', 'wporg_custom', 10, 2 );

function wporg_custom( $post_id, $post ) {
    // يمكنك الآن استخدام $post_id و كائن $post
}
