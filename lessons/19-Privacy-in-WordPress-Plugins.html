الخصوصية وحماية البيانات في الإضافات (Privacy & Data Protection)

دليل شامل لحماية بيانات المستخدمين، الامتثال لـ GDPR، تدمير البيانات وحذفها، تصدير البيانات، واقتراح سياسة الخصوصية.

1. ما هي الخصوصية في ووردبريس؟ (What is Privacy?)

إذا كنت تقوم بتطوير إضافة تتعامل مع البيانات الشخصية للمستخدمين والزوار — مثل الأسماء، البريد الإلكتروني، العناوين، معرّفات IP، أو أي بيانات تُستخدم للتعرف على هوية الشخص — فمن الواجب الحذر لحماية هذه البيانات واحترام خصوصية زوار ومستخدمي الموقع.

منذ تحديث ووردبريس 4.9.6 وقبل انطلاق قانون حماية البيانات الأوروبي General Data Protection Regulation (GDPR)، أصبحت الخصوصية تركيزاً دائمياً في نواة ووردبريس Core. ورغم اختلاف القوانين والتشريعات حول العالم، هناك 11 مبدأ أساسياً في المعيار الدولي (ISO 29100 Privacy Framework) يُشترط تطبيقها:

المبدأ (ISO 29100 Principle) الشرح والاستخدام التطبيقي في ووردبريس
1. Consent and Choice (الموافقة والاختيار) إعطاء المستخدمين خيارات صريحة حول استخدام بياناتهم وتطلب موافقة واضحة ومسبقة (Opt-in).
2. Purpose Legitimacy (شرعية وتحديد الهدف) جمع البيانات فقط للغرض المعلن عنه مسبقاً وبشكل شفاف دون استخدامها لأغراض أخرى.
3. Collection Limitation (الحد من جمع البيانات) جمع البيانات المطلوبة فقط لتشغيل الميزة، وتجنب نسخ البيانات أو دمجها مع إضافات أخرى.
4. Data Minimization (تقليل البيانات لأدنى حد) تقييد معالجة البيانات والحد من عدد الأشخاص الذين يمتلكون صلاحية الوصول إليها.
5. Retention & Disclosure (تقييد الحفظ والإفصاح) حذف البيانات التي لم تعد هناك حاجة إليها فوراً من النشاط والأرشيف.
6. Accuracy and Quality (دقة وجودة البيانات) ضمان أن البيانات التابعة للمستخدم صحيحة ومحدثة ولا تتسبب في أضرار في حال خطأها.
7. Openness & Transparency (الشفافية والإفصاح) إعلام المستخدمين بكيفية جمع بياناتهم واستخدامها ومشاركتها مع أطراف خارجية.
8. Individual Access (وصول الفرد لبياناته) منح المستخدمين وسيلة لتنزيل بياناتهم الشخصية أو طلب حذفها بالكامل.
9. Accountability (المساءلة والتوثيق) توثيق استخدامات البيانات وحمايتها أثناء النقل والتشغيل ومنع ثغرات الاختراق.
10. Information Security (أمان المعلومات) حماية البيانات الفنيّة عبر وسائط تشفير وتقنيات أمنية معتمدة.
11. Privacy Compliance (الامتثال التشريعي) التأكد من التوافق مع القوانين المحلية والدولية للمكان الذي تُعالج فيه البيانات.

2. إطار عمل الخصوصية بالتصميم (Privacy By Design Framework)

تتمحور فكرة الخصوصية بالتصميم حول أن الخصوصية ليست مجرد ميزة إضافية (Add-on)، بل هي **عنصر أساسي في أصل هيكلة الكود**:

  • استباقية وليست تفاعلية (Proactive, Not Reactive): تتوقع مشكلات الخصوصية وقلق المستخدم قبل حدوثه وتمنعه مسبقاً.
  • الخصوصية كإعداد افتراضي (Privacy as Default): لا يجب على المستخدم اتخاذ خطوات معقدة لتأمين خصوصيته، والموافقة لا تُفترض تلقائياً.
  • مدمجة في التصميم (Built into Design): الوظائف البرمجية تُبنى منذ اللحظة الأولى لحماية البيانات.
  • معادلة إيجابية (Positive Sum): لا يوجد تنازل أو مقايضة بين الأمان والخصوصية أو الأداء والخصوصية.
  • حماية دورة الحياة الكاملة (End-to-End Protection): حماية البيانات من وقت جمعها وحتى حذفها النهائي والتخلص منها.
  • شفافة وقابلة للتحقق (Transparent & Verifiable): المعايير المستخدمة مفتوحة وموثقة ويمكن التحقق منها بشكل مستقل.
  • تتمحور حول المستخدم (User-Centric): منح المستخدمين التحكم الكامل والتنبيهات المباشرة والتفصيلية.

3. أسئلة التدقيق الذاتي لإضافتك (Food for Thought for Your Plugin)

لكي تضمن جاهزية إضافتك للتوافق مع متطلبات الخصوصية، ينبغي مراجعة هذه الأسئلة الفاحصة قبل إطلاق الإضافة:

📋 قائمة مراجعة الخصوصية لإضافتك (Privacy Checklist):
  1. هل تشارك الإضافة بيانات مع أطراف خارجية (External APIs / Servers)؟ وما هي السياسة المتبعة؟
  2. هل تجمع الإضافة بيانات شخصية؟ وأين تُخزن (Options, Meta, Custom Tables, Files)؟
  3. هل تضمن الإضافة مكتبات SDKs خارجية؟ وماذا تفعل هذه المكتبات بالبيانات؟
  4. هل تجمع بيانات قياس عن بُعد (Telemetry Data) مباشرة أو غير مباشرة؟ (مثل تحميل صورة من سيرفر خارجي عند التثبيت).
  5. هل تُدرج ملفات JS أو Tracking Pixels أو iFrames من أطراف خارجية؟
  6. هل تُخزن بيانات في متصفح الزائر (Cookies / LocalStorage)؟
  7. هل توفر الإضافة Personal Data Exporter و Personal Data Eraser؟
  8. هل تمنع الإضافة تسجيل البيانات الشخصية داخل ملفات سجل الأخطاء Debug Logs بواسطة wp_privacy_anonymize_data؟
  9. ما هي الصلاحية (Capability) المطلوبة لرؤية البيانات الشخصية في wp-admin؟
  10. ما هي البيانات المعروضة في واجهة الموقع (Front-end) أو الـ REST API؟ وهل تقتصر على الأدوار المناسبة؟
  11. هل تنظف الإضافة بياناتها بالكامل عند الحذف النهائي (Uninstall) أو عند حذف المستخدم؟

4. إضافة ممحاة البيانات الشخصية (Adding Personal Data Eraser)

منذ إصدار ووردبريس 4.9.6، تم تقديم أداة Personal Data Eraser لحذف أو تجهيل البيانات الشخصية لمستخدم معين بناءً على البريد الإلكتروني. تعتمد الآلية على نظام الدُفعات (AJAX Loops with Pagination) لمنع حدوث انتهاء وقت السيرفر (Timeouts) عبر البرامتر $page.

مثال عملي: حذف بيانات الموقع الجغرافي المسجلة في التعليقات عبر wp_privacy_personal_data_erasers

privacy-data-eraser.php
<?php
/**
 * 1. دالة حذف بيانات الإحداثيات الشخصية المستهدفة عبر البريد الإلكتروني
 *
 * @param string $email_address البريد الإلكتروني المطلوب حذف بياناته
 * @param int    $page          رقم الصفحة لمنع حدوث Timeout
 * @return array
 */
function wporg_remove_location_meta_from_comments_for_email( $email_address, $page = 1 ) {
    $number = 500; // تحديد عدد 500 تعليق في المرة الواحدة لتفادي تجميد الخادم
    $page   = (int) $page;

    $comments = get_comments( array(
        'author_email' => $email_address,
        'number'       => $number,
        'paged'        => $page,
        'order_by'     => 'comment_ID',
        'order'        => 'ASC',
    ) );

    $items_removed = false;

    foreach ( (array) $comments as $comment ) {
        $latitude  = get_comment_meta( $comment->comment_ID, 'latitude', true );
        $longitude = get_comment_meta( $comment->comment_ID, 'longitude', true );

        if ( ! empty( $latitude ) ) {
            delete_comment_meta( $comment->comment_ID, 'latitude' );
            $items_removed = true;
        }

        if ( ! empty( $longitude ) ) {
            delete_comment_meta( $comment->comment_ID, 'longitude' );
            $items_removed = true;
        }
    }

    // إعلام النظام بما إذا كانت هناك صفحات تعليقات أخرى متبقية
    $done = count( $comments ) < $number;

    return array(
        'items_removed'  => $items_removed,
        'items_retained' => false,
        'messages'       => array(),
        'done''           => $done,
    );
}

/**
 * 2. تسجيل دالة الممحاة عبر الفلتر wp_privacy_personal_data_erasers
 */
function wporg_register_privacy_erasers( $erasers ) {
    $erasers['my-plugin-slug'] = array(
        'eraser_friendly_name' => __( 'Comment Location Plugin', 'text-domain' ),
        'callback'             => 'wporg_remove_location_meta_from_comments_for_email',
    );
    return $erasers;
}
add_filter( 'wp_privacy_personal_data_erasers', 'wporg_register_privacy_erasers' );

5. إضافة مصدّر البيانات الشخصية (Adding Personal Data Exporter)

يتيح مصدّر البيانات للمستخدم تنزيل تقرير شامل بكل بياناته الشخصية المسجلة داخل إضافتك. يتم تسجيل المصدّر عبر الفلتر wp_privacy_personal_data_exporters:

privacy-data-exporter.php
<?php
/**
 * 1. دالة تجميع وتصدير بيانات إحداثيات التعليقات
 */
function wporg_export_location_meta_from_comments_for_email( $email_address, $page = 1 ) {
    $number       = 500;
    $page         = (int) $page;
    $export_items = array();

    $comments = get_comments( array(
        'author_email' => $email_address,
        'number'       => $number,
        'paged'        => $page,
        'order_by'     => 'comment_ID',
        'order'        => 'ASC',
    ) );

    foreach ( (array) $comments as $comment ) {
        $latitude  = get_comment_meta( $comment->comment_ID, 'latitude', true );
        $longitude = get_comment_meta( $comment->comment_ID, 'longitude', true );

        if ( ! empty( $latitude ) || ! empty( $longitude ) ) {
            $data = array();
            if ( ! empty( $latitude ) ) {
                $data[] = array( 'name' => __( 'Latitude', 'text-domain' ), 'value' => $latitude );
            }
            if ( ! empty( $longitude ) ) {
                $data[] = array( 'name' => __( 'Longitude', 'text-domain' ), 'value' => $longitude );
            }

            $export_items[] = array(
                'group_id'    => 'comment-location',
                'group_label' => __( 'Comment Locations', 'text-domain' ),
                'item_id'     => "comment-location-{$comment->comment_ID}",
                'data'        => $data,
            );
        }
    }

    $done = count( $comments ) < $number;

    return array(
        'data' => $export_items,
        'done' => $done,
    );
}

/**
 * 2. تسجيل المصدّر عبر الفلتر wp_privacy_personal_data_exporters
 */
function wporg_register_privacy_exporters( $exporters ) {
    $exporters['my-plugin-slug'] = array(
        'exporter_friendly_name' => __( 'Comment Location Plugin', 'text-domain' ),
        'callback'               => 'wporg_export_location_meta_from_comments_for_email',
    );
    return $exporters;
}
add_filter( 'wp_privacy_personal_data_exporters', 'wporg_register_privacy_exporters' );

6. الخيارات والخطاطيف والصلاحيات المتاحة (Options, Hooks & Capabilities)

النوع (Type) اسم الخطاف / الخيار / الصلاحية الوصف والاستخدام التقني
Option wp_page_for_privacy_policy يحتوي على ID صفحة سياسة الخصوصية المعينة للموقع.
Action user_request_action_confirmed يُطلق فور تأكيد المستخدم لطلب التصدير أو الحذف.
Action wp_privacy_personal_data_erased يُطلق بعد اكتمال الصفحة الأخيرة من آخر عملية مسح بيانات.
Filter wp_privacy_personal_data_erasers لتسجيل دوال ممحاة البيانات الشخصية التابعة للإضافات.
Filter wp_privacy_personal_data_exporters لتسجيل دوال تصدير البيانات الشخصية التابعة للإضافات.
Filter wp_privacy_anonymize_data لتصفية وتجهيل البيانات المسجلة لتجريدها من الهوية.
Capability erase_others_personal_data يحدد إمكانية الوصول لقائمة **مسح البيانات الشخصية** تحت Tools.
Capability export_others_personal_data يحدد إمكانية الوصول لقائمة **تصدير البيانات الشخصية** تحت Tools.
Capability manage_privacy_options يحدد إمكانية الوصول لصفحة **الخصوصية** تحت Settings.

7. اقتراح نص لسياسة خصوصية الموقع (Suggesting Text for Privacy Policy)

كل إضافة تجمع أو تُخزن بيانات شخصية ينبغي أن توفر نصاً مقترحاً لمدير الموقع لإدراجه في صفحة سياسة الخصوصية. يتم ذلك عبر الدالة القياسية wp_add_privacy_policy_content() والمربوطة بالـ Action admin_init:

suggest-privacy-policy.php
<?php
/**
 * إضافة نص سياسة الخصوصية المقترح لإضافتك في صفحة إرشادات الخصوصية
 */
function wporg_add_privacy_policy_content() {
    if ( ! function_exists( 'wp_add_privacy_policy_content' ) ) {
        return;
    }

    $content = '<p class="privacy-policy-tutorial">' . __( 'Some introductory content for the suggested text.', 'text-domain' ) . '</p>' .
               '<strong class="privacy-policy-tutorial">' . __( 'Suggested Text:', 'text-domain' ) . '</strong> ' .
               sprintf(
                   __( 'When you leave a comment on this site, we send your name, email address, IP address and comment text to example.com. Example.com does not retain your personal data. The example.com privacy policy is <a href="%1$s" target="_blank">here</a>.', 'text-domain' ),
                   'https://example.com/privacy-policy'
               );

    wp_add_privacy_policy_content( 'Example Plugin', wp_kses_post( wpautop( $content, false ) ) );
}
add_action( 'admin_init', 'wporg_add_privacy_policy_content' );
